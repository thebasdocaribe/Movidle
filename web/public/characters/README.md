# Fotos do modo Personagem

Coloque stills de **corpo inteiro** (ou 3/4) com o nome do arquivo abaixo.
O jogo corta: pés → braço → cabelo → rosto → busto → completo.

## Convenção

O banco aponta para `/characters/{slug}.jpg`.

Exemplos (slug a partir do nome PT do catálogo):

| Personagem        | Arquivo              |
|-------------------|----------------------|
| Conde Orlok       | `conde-orlok.jpg`    |
| Neo               | `neo.jpg`            |
| Homem de Lata     | `homem-de-lata.jpg`  |
| Darth Vader       | `darth-vader.jpg`    |
| Freddy Krueger    | `freddy-krueger.jpg` |

Regra do slug: minúsculas, sem acento, espaços → `-`.

Formato: JPG ou PNG (se PNG, avise pra ajustarmos a extensão no banco).
Preferência: fundo simples, personagem centralizado, resolução ≥ 800px de altura.
